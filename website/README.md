# J&F Originals – product website (version 1)

A static product showcase in German (default) and English. It has no shop of its own: the buttons link to the Amazon and Etsy listings. There are no cookies, no tracking and no external requests, and the fonts are self-hosted.

## Preview locally

**Easiest:** double-click `index.html` in this folder. It opens in your browser and everything works, including the DE/EN switch and the legal pages.

**Optional, closer to a real web server** (needs Python):

```bash
cd website
python -m http.server 8000
```

Then open http://localhost:8000 in the browser.

## Open placeholders `[PLATZHALTER]`

They show up highlighted in yellow on the pages, so nothing goes live unchecked.

1. **Dua stickers:** sticker or sheet size.
2. **Dua stickers:** waterproof? Removable without residue?
3. **Salt grinder:** name as on the label (e.g. "Steinsalz aus Pakistan, grob").
4. **Salt grinder:** final label text.
5. **Crochet baby outfit set:** items in the set, size/age, colour, care instructions. So far only "pure wool" is taken from the Etsy listing title.
6. **Etsy shop URL.** The buttons currently link to the single crochet listing.
7. **Amazon storefront URL**, if there is one. The "Wo kaufen?" button currently links to the Dua sticker listing B0F8VQGDZ8.
8. **Privacy policy:** hosting provider, its address and the data processing agreement.
9. **Privacy policy:** server log retention period, as stated by the host.
10. **Privacy policy:** date ("Stand").
