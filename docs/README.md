# J&F Originals – product website (version 1)

A static product showcase in German (default) and English. It has no shop of its own: the buttons link to the Amazon and Etsy listings. There are no cookies, no tracking and no external requests, and the fonts are self-hosted.

## Preview locally

**Easiest:** double-click `index.html` in this folder. It opens in your browser and everything works, including the DE/EN switch and the legal pages.

**Optional, closer to a real web server** (needs Python):

```bash
cd docs
python -m http.server 8000
```

Then open http://localhost:8000 in the browser.
